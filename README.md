# Свадебное приглашение — Данил & Дарья

Статический сайт на HTML/CSS/Vanilla JS. Его можно разместить на GitHub Pages, а ответы RSVP сохранять в Google Sheets через Google Apps Script.

## 1. Подготовьте Google Таблицу

1. Создайте новую таблицу в Google Sheets.
2. Скопируйте её ID из адреса. Например, в `https://docs.google.com/spreadsheets/d/ABC123xyz/edit` ID — это `ABC123xyz`.
3. Откройте **Расширения → Apps Script**.
4. Удалите примерный код и вставьте содержимое файла `Code.gs`.
5. В начале `Code.gs` замените `ВСТАВЬТЕ_ID_GOOGLE_ТАБЛИЦЫ` на ID своей таблицы.
6. Сохраните проект. При первом запуске Google запросит разрешение на доступ к таблице — подтвердите его от имени владельца.

Лист `Ответы` и заголовки колонок создаются автоматически при первом запросе. Колонки: timestamp, имя, фамилия, приду/не приду, способ связи, контакт, алкоголь.

## 2. Разверните Apps Script как Web App

1. В редакторе Apps Script нажмите **Развернуть → Новое развертывание**.
2. Нажмите на шестерёнку и выберите тип **Веб-приложение**.
3. В поле «Выполнять от имени» выберите **Я**.
4. В поле «У кого есть доступ» выберите **Все** (или «Все, даже анонимные», если такой вариант отображается).
5. Нажмите «Развернуть» и пройдите авторизацию.
6. Скопируйте URL веб-приложения. Он обычно заканчивается на `/exec`. Используйте именно URL развертывания, не URL редактора.
7. После изменения `Code.gs` создавайте новое развертывание версии или обновляйте существующее через **Развернуть → Управление развертываниями → Изменить → Новая версия**.

> Веб-приложение доступно публично, чтобы гости могли отправлять RSVP. Не размещайте в таблице лишние персональные данные. Ответы содержат имена и контактные данные гостей — ограничьте доступ к самой таблице.

## 3. Подключите сайт к Apps Script

Откройте `script.js` и `admin.js`. В каждом файле найдите:

```js
const GOOGLE_SCRIPT_URL = "ВСТАВЬТЕ_URL_ВЕБ_ПРИЛОЖЕНИЯ";
```

Вставьте скопированный URL `/exec`, например:

```js
const GOOGLE_SCRIPT_URL = "https://script.google.com/macros/s/ВАШ_ID_РАЗВЕРТЫВАНИЯ/exec";
```

Сохраните оба файла. Для формы используется POST с `no-cors`: браузер отправляет данные, но не позволяет странице прочитать ответ Apps Script. Поэтому интерфейс показывает подтверждение после успешного выполнения сетевого запроса, но это не является подтверждением записи на стороне Google. После тестовой отправки обязательно проверьте, появилась ли строка в таблице.

Админка загружает строки через JSONP (`doGet`). Это избавляет от необходимости настраивать CORS. Веб-приложение должно быть развернуто с доступом «Все».

## 4. Пароль страницы администратора

В `admin.js` задан простой пароль:

```js
const ADMIN_PASSWORD = "admin123";
```

Замените его на свой. Это только защита от случайного просмотра: пароль находится в JavaScript и его можно увидеть в исходном коде сайта. Страница не является защищённой системой авторизации. Кроме того, URL публичного Web App позволяет получить данные через `doGet`, поэтому не считайте клиентский пароль защитой персональных данных. Если нужна реальная приватность, потребуется серверная авторизация или иной закрытый способ доступа.

## 5. Опубликуйте сайт на GitHub Pages

1. Создайте новый GitHub-репозиторий, например `wedding-invitation`.
2. Загрузите в корень репозитория файлы:
   - `index.html`
   - `admin.html`
   - `style.css`
   - `script.js`
   - `admin.js`
   - `README.md`
   - `Code.gs` (справочный файл; сайту он не нужен)
3. Откройте **Settings → Pages**.
4. В разделе Build and deployment выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/ (root)`, затем нажмите **Save**.
6. Через некоторое время GitHub покажет адрес сайта. Главная будет доступна по адресу сайта, админка — по адресу `.../admin.html`.

Если сайт находится в репозитории проекта, а не в репозитории `username.github.io`, GitHub Pages добавит имя репозитория в адрес. Относительные пути в проекте уже рассчитаны на такой вариант.

## 6. Проверьте перед отправкой гостям

1. Откройте опубликованный сайт и отправьте тестовый ответ.
2. Убедитесь, что новая строка появилась в листе `Ответы`.
3. Откройте `.../admin.html`, введите пароль и проверьте, что ответ отображается.
4. Проверьте оба варианта связи (Email и телефон), оба статуса посещения и множественный выбор напитков.
5. Удалите тестовые строки из таблицы перед рассылкой приглашений.

## Примечания

- Время мероприятия пока оставлено как «Время уточняется» — замените текст в `index.html`, когда время будет известно.
- Дата RSVP «до 01.08.2027» — при необходимости измените её в `index.html`.
- Сайт не использует сервер на GitHub Pages: HTML/CSS/JS обслуживаются статически, а запись/чтение данных выполняет Google Apps Script.
- Для отправки используется `fetch` с `mode: "no-cors"` и `Content-Type: text/plain`, чтобы избежать CORS preflight. Ответ браузера непрозрачен, поэтому окончательно проверяйте запись в таблице.
